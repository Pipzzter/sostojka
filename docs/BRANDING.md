# Sostojka

**Display name:** Состојка · Sostojka  
**Suggested GitHub repository name:** `sostojka`

Sostojka (состојка) means “ingredient” in Macedonian. It connects the project's local recipe collection with its focus on ingredient matching.

## GitHub repository description

Explore Macedonian recipes and link ingredients to USDA FoodData Central with AI-assisted translation, recipe context, and visual match explanations.
